Model source and implementation details

Quantities describing the current build — 50,048 parcels, the 72 × 36 × 9 analysis grid, 241 CRI species, 591 thermal + 110 photolysis rates, the INICON/RESTART cold-/warm-start logic, altitude-resolved ACNOX/LNOX emission files gated by DONO2, and the .dat/.bud/.tot/.sta outputs — are taken from the STOCHEM Fortran source (Base.for / Base_omp.for and INOPERVM10.SOA2) maintained in the local STOCHEM.jl repository. See the project STOCHEM_README.md for build and run documentation.

Interactive figures on the visualisations page are labelled schematics; they illustrate the mechanisms described in [1], [2] and [3]–[6] but are not model output. The GIFs are rendered from real model files or explicit reaction specifications.
