# stochem-cri-site

A private, dependency-free static website that explains **how STOCHEM-CRI
works** — the global 3-D Lagrangian tropospheric chemistry–transport model
developed at the UK Met Office / University of Bristol — with interactive
visualisations and full citations.

## What's in it

| Page | Content |
|---|---|
| `index.html` | Overview: the Lagrangian idea in one page, key numbers, timestep pipeline |
| `model.html` | Architecture: Eulerian meteorology vs Lagrangian parcels, grid, operator splitting, stochastic mixing, convection, emissions, deposition, restarts, output files |
| `chemistry.html` | The CRI v2-R5 mechanism: MCM reduction, photolysis, PAN/RO₂NO₂/HNO₃ reservoirs, SOA module |
| `visualisations.html` | Three interactive canvas/SVG demos + real GIFs rendered from model code/output |
| `references.html` | Full peer-reviewed citation list with DOIs |

## Interactive figures

All JavaScript is hand-written, dependency-free and runs locally — no CDN, no
build step, no frameworks:

- `assets/js/parcels.js` — schematic Lagrangian parcel advection with an
  interactive emission source and an "Eulerian grid-mean" overlay showing how
  parcels are binned onto the 72×36 analysis grid.
- `assets/js/chemistry.js` — clickable O₃–NOₓ–HOₓ–VOC reaction-network explorer
  with a day/night photolysis toggle.
- `assets/js/grid.js` — schematic zonal-mean field viewer on the 36×9 analysis
  grid using the manuscript's discrete rainbow palette.

The animated GIFs under `assets/img/` are **real** products generated by the
user's `reaction_anims` (reaction specification JSON + matplotlib/Pillow) and
`stochem_anims` (model code/output renderers) pipelines in the `Trading`
workspace — not stock art.

## Running locally

No build is needed. Either open `index.html` directly, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Deployment (GitHub Pages)

The repo is **private**; Pages on private repos requires GitHub Pro/Team.
Deployment is via GitHub Actions (`.github/workflows/pages.yml`), which uploads
the repo root as the Pages artifact on every push to `main`. Enable once with:

```bash
gh api repos/<owner>/stochem-cri-site/pages -X POST -f build_type=workflow
```

or in **Settings → Pages → Build and deployment → GitHub Actions**.

## Editing conventions

- Keep the site **self-contained**: no external JS/CSS/fonts/CDNs.
- Every factual claim about the model must cite `references.html` or the
  Fortran source. Do not invent citation details — verify against the DOI.
- Interactive figures must be labelled as *schematic*; only GIFs rendered from
  model files may be presented as real output.
- Match `assets/css/style.css` conventions (dark theme, `.panel`, `.viz`,
  `.cards`, `.schematic`, `.tip`) when adding pages, and add the page to the
  shared nav bar on **all** pages.
- Keep GIF assets reasonably small (< ~5 MB); prefer montage PNGs for larger
  animations.

See `AGENTS.md` and `.agents/skills/stochem-cri-site/SKILL.md` for the
maintenance runbook.
